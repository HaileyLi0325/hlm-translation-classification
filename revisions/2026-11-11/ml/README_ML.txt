MACHINE LEARNING AND SEGMENT SAMPLING REPRODUCTION

Run commands from the extracted S2 File package root. Paths below assume the
package contains data/, source/, and ml/ directories. Install the root package
requirements in a Python 3.13 environment. The exact executed version was 3.13.0.

1. Reproduce the fixed chapter-grouped hold-out, performance intervals and SHAP

python ml/run_ml_revision.py --source-root source --feature-root data --output ml/results --stage heldout

This command consumes the supplied corrected feature matrices. It does not need
the source books. It fits the eight original model constructors in
source/run_hlm_classification.py and reconstructs their exact hard vote.

Optional: --datasets chapter_level or --datasets window_1500 reruns one dataset.
When existing results for the other dataset are present, they are preserved.

2. Reproduce alternative segment positions and their feature matrices

Obtain the same source PDFs legally. Compare them with the source-file checksums
in the package. The corrected parser must be source/run_hlm_pipeline.py from this
revision, not the uncorrected earlier parser.

python ml/extract_sampling_features.py --source-root source --hm-pdf source/data/raw_pdfs/Hawkes.pdf --yy-pdf source/data/raw_pdfs/Yangs.pdf --output ml/results --processes 4

These are the same local PDF paths used by the root extraction workflow.
Other legally obtained input paths can be supplied explicitly. No full source
text is included in the submitted archive. This command extracts chapters in memory and
exports only window positions, features, coverage records and metadata.

Alternatively, if the root extraction workflow has already created chapter text:

python ml/extract_sampling_features.py --source-root source --chapter-root PATH_TO_CHAPTER_DIRECTORY --output ml/results --processes 4

The chapter directory must contain hawkes/chapter_001.txt through chapter_120.txt
and corresponding yang/chapter_001.txt through chapter_120.txt. It must use the
final corrected chapter boundaries and recovered trailing tokens.

--processes 1 is supported on machines with limited memory. Changing the process
count does not change the feature definitions or random seeds.

3. Evaluate all five segment selection schemes with common grouped folds

python ml/run_ml_revision.py --source-root source --feature-root data --output ml/results --stage sampling

4. Audit the final outputs

python ml/audit_ml_outputs.py --results ml/results --feature-root data

The audit checks canonical-prefix feature agreement, exact word counts, window
nonoverlap, equal edition counts, source-chapter partitioning, unique out-of-fold
predictions, reconstructed hard voting, SHAP additivity and input hashes.

METHOD DEFINITIONS

The edition storage codes hawkes and yang mean Hawkes-Minford and Yang-Yang,
respectively. They do not denote two individually attributable translators.

For each source chapter, k=min(floor(L_HM/1500),floor(L_YY/1500)), where L is the
original regex-defined word count. Every scheme retains k windows per edition.
The final corpus has 120 source chapters and 361 windows per edition.

For zero-based window j, start=j*1500+offset_j. Prefix offsets are zero.
Position-stratified offsets are rounded linspace(0,L-1500*k,k), with a central
offset when k=1. Random-gap offsets are k sorted discrete Uniform(0,L-1500*k)
draws. Separate random streams use SeedSequence([seed,chapter,edition_index]),
where seed is 101,202,303 and edition_index is 0 for HM or 1 for YY. All windows
are exactly 1,500 regex words and nonoverlapping within a strategy/chapter/edition.
These procedures do not establish exact source-span alignment or equal coverage.

Five folds are generated by KFold(5,shuffle=True,random_state=42) on sorted source
chapter numbers. The same folds are used across schemes, editions and classifiers.
All observations from a source chapter stay together. Reported sampling means are
unweighted means of five fold accuracies; fold SD uses ddof=1.

The separate fixed hold-out uses default_rng(42).choice(sorted_chapters,24,
replace=False). All 24 held-out chapters appear in both editions and are excluded
from all training and scaling. The remaining 96 chapters form the training set.
The final test sizes are 48 complete chapters and 142 fixed-length segments.

Performance metrics use Yang-Yang as positive. Macro metrics average class-specific
values without weighting. Specificity is recall for Hawkes-Minford. AUC uses class
probabilities or decision_function scores, and is omitted for label-only voting.
All metric intervals are 2,000-draw percentile bootstraps over complete test-chapter
groups, seed 20261111. They are conditional on the fitted model and observed test
groups; they do not capture training-set or source-corpus uncertainty.

Hard voting uses the eight original default estimators. Five or more Yang-Yang
votes select that class; ties select Hawkes-Minford, matching sklearn class order.
For performance, fold-SD and gap comparisons, no claim of universal ensemble
superiority is warranted. Five-fold SD and repeated-split SD describe different
evaluation schemes and should not be conflated.

SHAP explains only held-out Random Forest observations. Each forest has 500 trees
and random_state=42. TreeExplainer uses feature_perturbation='tree_path_dependent'
and model_output='raw'. For these sklearn forests the explained raw class output
is probability. Training-path counts provide background information. The expected
value plus the SHAP sum is verified against predicted Yang-Yang probability.
Correlated features can share or redistribute attribution; SHAP is not causal.

EXACT EXECUTED SCIENTIFIC ENVIRONMENT

Python 3.13.0; NumPy 2.1.3; pandas 2.2.3; SciPy 1.15.1;
scikit-learn 1.7.2; spaCy 3.8.14; en_core_web_sm 3.8.0;
NLTK 3.9.4; wordfreq 3.1.1; SHAP 0.50.0; pypdf 6.10.2.

The English model is installed separately from spaCy. One exact installation is:
python -m pip install https://github.com/explosion/spacy-models/releases/download/en_core_web_sm-3.8.0/en_core_web_sm-3.8.0-py3-none-any.whl

Full configurations and results are recorded in ml/results/ml_metadata.json,
sampling_metadata.json, sampling_cv_manifest.json and heldout_manifest.json.
ML_methods_results.txt maps the final evidence to reviewer comment numbers.

Optional incremental extraction caches are a computation convenience. They are
not required for reproduction and should not be distributed as final results.
The original full-corpus and window texts remain under the reader's own lawful
access conditions. None of these scripts publishes files to GitHub.
